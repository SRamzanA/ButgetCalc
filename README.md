# ButgetCalc
Приложение для расчета и мониторинга бюджета каждый день. 
- "На карте" - это то, сколько по факту денег на карте.
- "Бюджет на день" - это число, которое расчитали в начале, оно не меняется.
- "Доступно" - это значение, в которое переносится остаток. было доступно 300, сегодня не рубля не потратили, тогда на завтра 300 + "Бюджет на день". Это число показывает, сколько вообще денег из всех доступно сегодня, что бы не остаться без денег потом. Добавляя доход он добавляется не только к балансу карты, но и в "Доступно".
- "Потрачено сегодня" - ну собственно траты. когда прибавляешь расход - увеличивается эта переменная и уменьшается "Осталось на день".
- "Осталось на день" - Каждый день в начале она обновляется в значение "Бюджет на день". Эта переменная показывает, какой лимит на день по плану и не привысил ли ты его. по сути ограничитель, но он не блокирует траты, просто показывает, выше какого значения желательно сегодня не тратить. Если значение "Доступно" меньше значения "Осталось на день", то советую ориентироваться на "Доступно".
